Programación para Artista I

Proyecto: Ecosistemas Algorítmicos

Agenda 2030 - ODS 15

Resumen

Este proyecto combina el arte y la programación. Se utiliza JavaScript para crear un árbol que cambia cada vez que hacemos clic.

Introducción

La programación puede utilizarse como una herramienta artística. En este proyecto usamos código para representar la naturaleza y la importancia de cuidar los ecosistemas.

Obra Interactiva

Haz clic en el botón o sobre el dibujo para crear un nuevo árbol.

Temas utilizados

  • Variables
  • Funciones
  • Condiciones
  • Recursividad
  • Canvas
  • Colores

Conclusión

Este proyecto demuestra que el código también puede utilizarse para crear obras de arte. La interacción permite que cada árbol sea diferente y representa la variedad de la naturaleza.
